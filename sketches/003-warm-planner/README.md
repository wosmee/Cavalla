## Variant: Тёплый дневник-планировщик

### Design stance
Классическая структура приложения с табами «Сегодня / Календарь / История» — каждая роль разнесена по своей вкладке, ничего не скроллится лишнего.

### Key choices
- Layout: таб-бар из трёх вкладок; «Сегодня» — круговая диаграмма + карточка-чекин
- Typography: округлые крупные заголовки, тепло-коричневый текст
- Color: кремово-персиковая гамма (#fdf8f3, терракота #c4545e) — «бумажный дневник»
- Interaction: переключение табов, сетка быстрых ответов-кнопок (2×4), кнопка активируется с выбором

### Trade-offs
- Strong at: каждая сущность (день, месяц, статистика) живёт на своей вкладке — масштабируется без ломки структуры; familiar-паттерн, ноль обучения
- Weak at: три вкладки на одну собаку может быть избыточно; «умность» не бьёт в глаза с первого экрана так, как в ленте

### Best for
- Долгого использования и мульти-собаки: вкладки не растут, а вот содержимое календаря/истории расширяется свободно
