# Cavalla

Telegram Mini App — календарь течки собак с умным прогнозом. Отмечайте дни цикла, симптомы и самочувствие — приложение уточняет фазу, прогнозирует следующую течку и предупреждает об отклонениях (например, признаках пиометры).

Живой бот: [@cavalla1_bot](https://t.me/cavalla1_bot) → `/start` → открыть мини-апп.

## Возможности

- **Профиль собаки** — кличка, порода, дата рождения, вес, фото-аватар; поддержка нескольких собак.
- **Учёт течек** — история циклов, интервалы, прогноз следующей течки по породе и персональной статистике.
- **Ежедневный чекин** — «всё хорошо» одним нажатием или отметка симптомов (выделения, поведение, самочувствие) с заметкой на день.
- **Уточнение фазы по симптомам** — признаки охоты (эструс) сдвигают окно фертильности; отклонения от «её нормы» подсвечиваются.
- **Предупреждения** — гнойные выделения → подсказка «когда к ветеринару»; затянувшаяся течка → мягкий намёк закрыть запись.
- **Календарь и история** — визуальная лента циклов, шторка любого дня, заметки течек.
- **Вет-сводка** — данные для визита к ветеринару одним текстом (копирование в буфер).
- **Уведомления** — дневной cron-напоминатель о чекине (07:17 мск) и подсказка о закрытии затянувшейся течки.
- **Гайд** — встроенный словарь терминов (проэструс, эструс, диэструс, ложная щенность, пиометра) внутри приложения.

## Стек

| Слой | Технология |
| --- | --- |
| Backend | Cloudflare Worker (TypeScript), Hono-подобная ручная маршрутизация |
| База | Cloudflare D1 (SQLite): `users`, `dogs`, `heats`, `daily_checkins`, `cron_locks` |
| Кэш | Cloudflare KV (кэш цикла, аватаров) |
| Бот | grammY (webhook-режим) |
| Frontend | Vanilla TS/HTML/CSS внутри Telegram WebView (без фреймворков и сборщиков) |
| Авторизация | Telegram WebApp initData (HMAC-проверка подписи на воркере) |

## Структура

```
worker/
  src/
    index.ts      — маршрутизация (API, /tg webhook, /cron, /bootstrap, статика)
    api.ts        — REST API (/api/dogs, /api/dogs/:id/heats, checkins, avatar…)
    auth.ts       — валидация initData, сессии пользователей
    bot.ts        — grammY-бот: /start, вебхук
    cycle.ts      — домен цикла: фазы, прогноз, детекторы симптомов
    breeds.ts     — интервалы течек по породам и размерным классам
    notify.ts     — cron-уведомления, антидубль-лок в D1
  migrations/     — SQL-миграции D1
  public/         — мини-апп (index.html + встроенные TS/CSS)
  test/           — тесты домена и API
sketches/         — ранние дизайн-скетчи интерфейса
```

## Свой деплой

1. Создайте ресурсы в своём аккаунте Cloudflare и пропишите в `worker/wrangler.toml`:
   ```bash
   wrangler d1 create cavalla
   wrangler kv namespace create KV
   ```
   Подставьте полученные `account_id`, `database_id`, KV `id`.
2. Примените миграции:
   ```bash
   wrangler d1 execute cavalla --remote --file=migrations/0001_init.sql
   # ... и остальные по порядку
   ```
3. Создайте бота у [@BotFather](https://t.me/BotFather), затем секреты:
   ```bash
   wrangler secret put BOT_TOKEN
   wrangler secret put WEBHOOK_SECRET   # любая стойкая случайная строка
   ```
4. Задеплойте и поставьте вебхук (воркер сам зовёт Telegram из датацентра CF):
   ```bash
   wrangler deploy
   curl "https://<ваш-воркер>.workers.dev/bootstrap?secret=<WEBHOOK_SECRET>"
   ```
5. В BotFather включите мини-апп: `/newapp` → укажите URL воркера.

Локальная разработка: `cd worker && npm install && npm run dev`. Тесты: `npm test` (Node 22+, тип-стриппинг для прямых импортов `.ts`).
